# Glyph-billeder (uploadede ikoner)

Læg færdige ikon-billeder her — én fil pr. glyf.

## Format
- **Transparent baggrund** (PNG med alpha, eller SVG)
- **Kvadratisk canvas**, ensartet optisk størrelse på tværs (glyffen fylder ~85 %, centreret)
- **Høj opløsning:** ~192–256 px (vises ved 16–48 px → skaleres skarpt ned)

## Navngivning (lowercase, ø→oe)
- `fugl.png`
- `hvidloeg.png`
- `pindsvin.png`
- `plante.png`
- (frøbank-kategorier hvis de også uploades: `froe.png`, `loeg.png`, `knolde.png`, `buske.png`, `traeer.png`, `stauder.png`)

Claude wirer dem ind på /glyf-pilot + i frøbanken når de ligger her.
